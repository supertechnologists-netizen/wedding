Адрес: https://supertechnologists-netizen.github.io/wedding/damir/

```

img/hero.jpg            — акварельные ветки для первого экрана
```

## Как поменять данные

Все данные в одном месте: блок `SETTINGS` в начале скрипта в `index.html`
(ищите строку `var SETTINGS`). Текст в квадратных скобках — заглушка.

| Что | Поле | Сейчас |
|---|---|---|
| Дата | `date` | `2027-04-10` (день недели считается сам) |
| Время Хрещення | `time` | `12:00` |
| Часовой пояс | `utcOffset` | `+03:00` — Киев, летнее время |
| Церковь | `church.name`, `church.address` | `[НАЗВА ЦЕРКВИ / ХРАМУ]`, `[АДРЕСА]` |
| Карта церкви | `church.map` | ссылка Google Maps |
| Время фото | `photoTime` | `[ЧАС]` |
| Ресторан | `restaurant.name`, `.time`, `.address`, `.map` | «Золотогор», `[ЧАС]`, `[АДРЕСА]`, ссылка |
| Телефоны | `phones.yulia`, `phones.zhenya` | номера Юли и Жени |
| Дресс-код | `dressCode` | `true` — показан, `false` — скрыт |
| Анкета | `rsvpEndpoint` | пусто = демо-режим |

Если поле сделать пустым (`''`), эта строка на сайте не показывается.

Таймер считает до даты и времени Хрещення. После начала вместо таймера — «Сьогодні особливий день».

## Анкета → Google Таблица

Пока `rsvpEndpoint` пустой, анкета работает в демо-режиме: гость видит «Дякуємо!», но ответ никуда
не сохраняется, а под кнопкой написано «Демо-режим». Чтобы ответы сохранялись:

1. Создать **новую** таблицу: https://sheets.new (не свадебную, чтобы ответы не смешались).
2. **Расширения → Apps Script** → удалить всё в редакторе → вставить содержимое `rsvp/Code.gs` → сохранить.
3. **Начать развертывание → Новое развертывание → Веб-приложение**:
   запуск от имени «Я», доступ «Все». Разрешить доступ. Скопировать URL, который заканчивается на `/exec`.
4. Вставить этот URL в `rsvpEndpoint` в `index.html`.
5. Отправить тестовую анкету и проверить, что в таблице появилась строка.

Колонки таблицы: Час, Ім’я та прізвище, Чи буде, Супровід, Ім’я гостя, Побажання / обмеження.

Защита: скрытое поле-ловушка для ботов, не больше 100 ответов за 10 минут и 5 в час с одним именем,
обрезка длины полей, защита от формул в таблице.
