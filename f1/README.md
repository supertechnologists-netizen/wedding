# ANNA & ANDRII — весільне запрошення з відсилками до Formula 1

Світлий весільний сайт-запрошення (з легкими F1-деталями: стартові вогні, прапорці, болід) + RSVP, база даних і приватна адмін-панель.
Без залежностей: потрібен лише **Node.js ≥ 22.5** (SQLite вбудований — `node:sqlite`).

## Запуск

```bash
cd f1
ADMIN_PASSWORD='ваш-надійний-пароль' PORT=3000 npm start
```

- Сайт: `http://localhost:3000/`
- Адмін-панель: `http://localhost:3000/admin`
- Дані: `f1/data/wedding.db` (SQLite), завантажені фото — `f1/data/uploads/`. Робіть резервну копію папки `data/`.
- Змінні: `ADMIN_PASSWORD` (обов’язково змінити!), `PORT`, `DATA_DIR`, `SECRET` (необов’язково).
- За reverse-proxy з HTTPS передавайте `X-Forwarded-Proto`/`X-Forwarded-For` (cookie стане `Secure`).

Потрібен сервер, де працює Node (VPS, Render, Railway, Fly.io…) — GitHub Pages не підійде, бо відповіді гостей зберігаються в БД.

## Що вміє

**Публічний сайт:** заставка зі стартовими вогнями (болід з обличчями пари) → hero з вініловою кнопкою музики та фото пари → «Про нас» → таймер у кольорах команд F1 → «Програма дня»: звивиста пунктирна дорога, болід із парою їде за скролом, огинає картки програми, на кожній точці — спалах і сердечка, у кінці — пін місця і конфеті → місце з картою → галерея → дрес-код (кольори команд F1 2024–2026) → «Замість квітів» → RSVP і побажання (пелюстки при «Так, буду!») → нічний фінал: болід із бляшанками перетинає фінішну лінію — і починається салют (є кнопка «Запустити салют»). Музика/ефекти вмикаються окремими кнопками. Повністю адаптивний, поважає `prefers-reduced-motion`.

**Маленькі радощі:** подвійний тап по фото — сердечко як в Instagram; тап по машинці — гудок і сердечка; тап по картці програми, таймеру, кольору дрес-коду — святкові бризки; пʼять тапів по логотипу A♥A — дощ із сердечок.

**Заглушки фото:** `public/img/*.svg` — намальовані ілюстрації (пара в гоночних комбінезонах на тлі гір, портрети, 6 кадрів галереї, подарунки). Вони стоять за замовчуванням у `DEFAULTS` (`server.js`), щоб сайт одразу виглядав наповненим. Справжні фото завантажуються в адмінці й замінюють їх. Згенеровано скриптом `tools/make-illustrations.py`.

**Персональні посилання:** в адмінці додайте гостей (по одному в рядок) і скопіюйте посилання виду `/?g=КОД` — ім’я гостя з’явиться у привітанні, а форма заповниться автоматично. Загальне посилання теж працює (відповідь створює нового гостя).

**RSVP:** ім’я, прийду/ні, супутник, харчові побажання, напої (мультивибір). Список напоїв редагується в адмінці.

**Адмінка (`/admin`, пароль):** статистика й діаграми, список гостей (фільтри, редагування, видалення, посилання), побажання, редагування всього контенту (імена, дата, місце, карта, біографії, фото/завантаження, галерея, кольори дрес-коду з назвами, програма дня, напої), експорт у CSV (відкривається в Excel).

## Безпека
Пароль порівнюється у постійний час, сесія — підписаний HttpOnly cookie на 7 днів, ліміт спроб входу, ліміти на відправку форм, перевірка Origin для змін, весь вивід екранується.
