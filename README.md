# Юлія & Євгеній — сайт-запрошення на весілля

Односторінковий статичний сайт без сервера и без сборки. Хостинг — GitHub Pages.

## Структура

```
index.html   — весь сайт: разметка, стили, скрипты
guests.html  — приватный дашборд молодожёнов (открывается по ссылке с ключом)
photo.jpg    — фото пары (блок «Запрошуємо вас»)
rsvp/        — скрипт Google Apps Script для анкеты и инструкция
README.md    — этот файл
```

Внешние зависимости: только шрифты Google Fonts (Cormorant Garamond и Jost).

## Разделы страницы

1. Обложка с именами
2. Приглашение с фото
3. День свадьбы (дата)
4. Место: Каспій Преміум
5. Время: 14:00
6. Дресс-код: красный, чёрный, бежевый
7. RSVP-анкета
8. Финальный блок с именами

## Заглушки, которые нужно заменить

| Что | Где в index.html | Сейчас |
|---|---|---|
| Дата свадьбы | блок `.date`, `.finale-date`, текст благодарности в скрипте | 17 жовтня 2026, субота |
| Срок ответа | `.rsvp .lead` | до 5 жовтня |
| Адрес / ссылка на карту | ссылка «Відкрити на мапі» | поиск «Каспій Преміум» в Google Картах |
| Анкета RSVP | `RSVP_ENDPOINT` в скрипте | пусто = демо; настройка в `rsvp/README.md` |

## Анкета гостей

Сайт статический, хранить ответы сам не может. Ответы уходят в Google Таблицу через Apps Script. Молодожёны смотрят их на приватной странице `guests.html#КЛЮЧ` (итоги, напитки, список, выгрузка в Excel). Подробно — `rsvp/README.md`.
Поля: имя и фамилия, телефон, будет ли гость (да / нет), сколько человек (1 / 2), напитки (несколько вариантов), комментарий.

## Публикация

1. Репозиторий должен быть **публичным** (бесплатный GitHub Pages работает только с публичными).
2. Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.
3. Сайт: https://supertechnologists-netizen.github.io/wedding/

## Ветки

- `main` — то, что видят гости. Сюда только через merge.
- `dev` — правки и эксперименты. Проверили → merge в `main` → сайт обновился через 1–2 минуты.

## После свадьбы

Settings → Pages → отключить, или удалить репозиторий целиком.
