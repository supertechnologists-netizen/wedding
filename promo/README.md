# Рекламні слайди «Сайти-запрошення»

Набір із 4 слайдів для Instagram / Telegram / Viber. Показує мій перший готовий сайт-запрошення
(весілля Юлії та Євгенія, `../index.html`) як портфоліо. Сам сайт у цій папці не змінюється.

## Готові файли — `out/`

| Формат | Розмір | Папка |
|---|---|---|
| Instagram-пост | 1080×1350 | `out/post/` |
| Квадрат | 1080×1080 | `out/square/` |
| Stories | 1080×1920 | `out/story/` |
| Для друку (PDF, текст векторний) | усі три формати | `out/print/` |

Слайди: `01-oblozhka` · `02-portfolio` · `03-shcho-vsered` · `04-kontakty`.

## Як змінити тексти, контакти, логотип

1. Відкрийте `content.js` і замініть `[Імʼя Прізвище]`, `[Телефон]`, `[Instagram]`, `[Email]`.
2. Логотип: покладіть файл у цю папку (напр. `logo.png`, прозорий фон) і вкажіть `logo: 'logo.png'`.
   Для темних слайдів можна окремо вказати світлу версію в `logoLight`.
3. Перезберіть картинки:
   ```
   npm i playwright        # один раз
   node render.mjs         # усі формати, або: node render.mjs post
   ```

Переглянути макет у браузері: `slides.html?f=post` (або `square`, `story`).

## Що всередині

- `slides.html` — макет усіх слайдів і трьох форматів (стилі, розкладка).
- `content.js` — усі тексти, контакти, логотип.
- `shots/` — реальні скриншоти першого сайту (мобільний екран, 3×). Оновити: `node shoot.mjs`.
- `fonts/` — Cormorant Garamond і Jost, ті самі шрифти, що й на сайті.
