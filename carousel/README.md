# Карусель для Instagram — сайти-запрошення

5 слайдів 1080 × 1350 (4:5). Без збирання й без встановлення залежностей.

```
index.html          — слайди, перегляд, експорт PNG, тексти для публікації
img/site-*.jpg      — скриншоти реального сайту-запрошення (мобільна версія)
png/                — готові PNG 1080 × 1350, можна одразу публікувати
vendor/             — бібліотека html-to-image (MIT) для збереження PNG у браузері
export-png.js       — необов'язково: збереження PNG через Node.js + Playwright
```

## 1. Як відкрити

- **Найпростіше:** після злиття в `main` карусель відкривається за адресою
  https://supertechnologists-netizen.github.io/wedding/carousel/
- **На комп'ютері:** відкрийте `index.html` у Chrome / Edge / Safari.
  Для кнопок збереження PNG краще запустити локальний сервер у папці `carousel`:
  `python3 -m http.server 8000` → http://localhost:8000
  (якщо файл відкрито напряму з диска, браузер не дозволяє зберігати PNG).

Кнопки вгорі: **Карусель** (по одному слайду; стрілки, клавіші ← →, свайп),
**Усі слайди** (огляд; клік відкриває слайд), **Скриншоти**, **Тексти** (підпис і сторіс
з кнопкою «Копіювати»), **PNG цього слайда**, **Зберегти всі 5 PNG**.
Окремий слайд у натуральному розмірі: `index.html?slide=1` … `?slide=5`.

## 2. Як замінити скриншоти

- **Тимчасово:** кнопка «Скриншоти» → «Замінити» → оберіть файл з телефона чи комп'ютера.
  Зображення запам'ятовується в цьому браузері; «Повернути стандартні» — скинути.
- **Назавжди:** покладіть свій файл у `img/` і вкажіть його назву в блоці `SCREENS`
  у кінці `index.html`. Найкраще — вертикальні скриншоти з телефона (≈ 9:19.5, напр. 1170 × 2532).

| Ключ | Що показує | Де |
|---|---|---|
| `hero` | обкладинка сайту | слайди 1, 2 |
| `invite` | блок «Запрошення» з фото | слайд 2 |
| `day` | дата, місце, час | слайди 2, 4 |

Слайд 3 — концепції стилів, зроблені кодом (без фото); у ньому немає чужих проєктів.

## 3. Як редагувати тексти

Увесь текст слайдів — прямо в розмітці `index.html`, кожен слайд позначено коментарем
`СЛАЙД 1 … СЛАЙД 5`. Назва вгорі слайдів — змінна `BRAND`, нік на останньому слайді —
`INSTAGRAM` (наприклад `'@my.invitations'`; порожньо — рядок не показується).
Кольори й шрифти — змінні на початку `<style>`. Підпис і сторіс — у панелі «Тексти»
(блоки `id="cap"`, `id="st1"`, `id="st2"`).

## 4. Як зберегти PNG для Instagram

- Готові файли вже лежать у `png/`.
- Після змін: «Зберегти всі 5 PNG» (браузер може спитати дозвіл на кілька файлів — дозвольте).
- Альтернатива: `npm i playwright && npx playwright install chromium`, потім `node export-png.js`
  у папці `carousel` — файли з'являться в `png/`.
- Без усього цього: відкрийте `index.html?slide=N`, у Chrome DevTools → ⋮ → Run command →
  «Capture node screenshot» на елементі `.slide`.

Публікація: завантажте 5 PNG в Instagram в порядку 01 → 05, формат 4:5.
