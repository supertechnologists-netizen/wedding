# Анкета RSVP → Google Таблица → дашборд молодожёнов

```
сайт index.html ──POST──▶ Google Apps Script ──▶ Google Таблица
                                   ▲
guests.html#КЛЮЧ ──GET?key=КЛЮЧ────┘   (без верного ключа — отказ)
```

- `index.html` — приглашение для всех гостей. Может только **отправить** ответ.
- `guests.html#КЛЮЧ` — приватный дашборд молодожёнов: итоги, напитки, список гостей,
  выгрузка в Excel. Обновляется сам раз в минуту.
- Ключ хранится только в Apps Script (в репозитории заглушка) и в ссылке молодожёнов.
  Ключ стоит после `#`, поэтому браузер не отправляет его на сервер GitHub Pages.

## Как это защищено

- **Один гость — одна строка на дашборде.** Гостя узнаём по номеру телефона (последние 9 цифр,
  так что `+380 67…` и `067…` — один номер). Если гость ответил повторно, считается последний ответ,
  а у гостя появляется пометка «Відповідь змінено». В Excel: лист «Гості» — итог, «Усі відповіді» — всё подряд.
- **Подтверждение.** «Дякуємо» гость видит только когда таблица ответила `ok`. Иначе — «спробуйте ще раз».
- **Спам.** Скрытое поле-ловушка для ботов, лимиты: 100 ответов за 10 минут всего, 5 в час с одного
  номера, 3000 строк максимум, обрезка длины полей, защита от формул.
- **Таблица.** Лист защищён: при ручной правке Google покажет предупреждение. Колонки дашборд ищет
  по названию, поэтому перестановка колонок его не ломает. Откатить случайную правку:
  Файл → История версий.
- **Доступ скрипта.** Строка `/** @OnlyCurrentDoc */` ограничивает его одной этой таблицей.
- **Версия.** `VERSION` в Code.gs и `SCRIPT_VERSION` в guests.html должны совпадать. Если скрипт
  в Google старее, на дашборде появится «Потрібне оновлення системи анкет».

## Настройка

1. https://sheets.new → **Расширения → Apps Script** → вставить `rsvp/Code.gs`.
2. В строке `var DASHBOARD_KEY = 'ВСТАВТЕ_КЛЮЧ';` заменить заглушку на свой ключ
   (длинная случайная строка из латиницы и цифр). Сохранить.
3. **Начать развертывание → Новое развертывание → Веб-приложение**:
   запуск от имени «Я», доступ «Все». Скопировать URL `.../exec`.
4. Вставить URL в `RSVP_ENDPOINT` (index.html) и `ENDPOINT` (guests.html).
5. Ссылка для молодожёнов: `https://<сайт>/guests.html#КЛЮЧ`.

## Обновление скрипта

**Развертывание → Управление развертываниями → ✏️ → Версия: «Новая версия» → Развернуть.**
URL при этом не меняется. Если сделать «Новое развертывание», URL будет другим — тогда сайт
покажет гостям «Не вдалося надіслати», и адрес нужно поменять в `index.html` и `guests.html`.

После каждого обновления: отправить тестовую анкету и проверить, что она появилась на дашборде.

## Сменить ключ (если ссылка утекла)

Поменять `DASHBOARD_KEY` в Apps Script, выпустить новую версию (см. выше) и отправить
молодожёнам новую ссылку. Старая сразу перестанет работать.
